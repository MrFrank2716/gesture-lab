Guided capture for a training set

Pick a gesture, press capture, and repeat the gesture on each GO beep. Every repeat is saved as its own labelled clip.

 

Clips are 1.5 s long and start a quarter second before the beep. As a rule of thumb, aim for 50 or more clips per gesture from several people, and include "still" and "other" so a model learns what is not a gesture. Use a code, not a name, for each participant.

How to hold it

Grip the phone like a handle with the top pointing away from you. A slide is a fast sideways sweep, as if cutting across a table top. A chop is a fast downward strike from the elbow. The detector works out which way is down from gravity, so the grip does not matter. Keep a firm hold and clear space around you.
